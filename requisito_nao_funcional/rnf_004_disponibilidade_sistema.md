## RNF-004 — Disponibilidade do Sistema

**Categoria:**  
Disponibilidade

**Descrição:**  
O sistema deve permanecer disponível para utilização durante o período de 
operação definido para o sistema.

**Justificativa:**  
Garantir que os usuários possam acessar suas contas e realizar operações 
quando o sistema estiver dentro do período de funcionamento estabelecido.

**Métrica/Critério mensurável:**  
O sistema deve apresentar disponibilidade mínima de 99% durante o período de 
operação definido, desconsiderando manutenções previamente programadas.

**Escopo:**  
Todo o sistema.

**Prioridade:**  
Alta

**Status:**  
Aprovado

**Requisitos relacionados:**  
RF-001, RF-002, RF-005, RF-007

**Casos de teste relacionados:**
