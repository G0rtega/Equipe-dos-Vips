## RNF-005 — Usabilidade da Interface

**Categoria:**  
Usabilidade

**Descrição:**  
O sistema deve apresentar uma interface clara e consistente, permitindo que 
os usuários compreendam as principais operações bancárias sem necessidade de 
conhecimento técnico.

**Justificativa:**  
Facilitar a utilização do sistema por clientes e reduzir erros durante a 
realização das operações.

**Métrica/Critério mensurável:**  
As operações principais de consulta de saldo, saque, transferência e consulta 
de histórico devem ser acessíveis em no máximo 3 etapas de interação a partir 
da tela principal após a autenticação.

**Escopo:**  
Interface das funcionalidades disponibilizadas aos usuários.

**Prioridade:**  
Média

**Status:**  
Aprovado

**Requisitos relacionados:**  
RF-002, RF-005, RF-007
